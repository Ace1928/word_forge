# Support

For usage questions, first run `word-forge doctor` and check the
[documentation](docs/README.md).

- Reproducible bug: open a GitHub issue with Word Forge version, Python version,
  operating system, command, expected result, actual result, and a minimal
  example that contains no private lexicon data.
- Feature proposal: open an issue describing the user problem before proposing
  a large implementation.
- Security concern: follow [SECURITY.md](SECURITY.md), not a public issue.

Community support is best-effort. No service-level agreement is implied by the
open-source license.
